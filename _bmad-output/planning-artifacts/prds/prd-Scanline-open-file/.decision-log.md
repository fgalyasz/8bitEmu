# Decision log: Open a file from the menu

## 2026-10-04 — One Open item, classified by extension

- **Decision:** File → Open… is one dialog. `.rom`, `.sna`, `.tap`, and `.tzx` select the loader. Cancel changes nothing.
- **Source:** Product request, 2026-10-04. The user asked for a menu item that chooses the file to load.
- **Landed in:** FR-1.

## 2026-10-04 — A booted tape load starts over

- **Decision:** Opening a tape on a booted machine resets it, then the existing `LOAD ""` prompt runs. Opening a tape before a ROM only inserts the tape.
- **Source:** The prompt types into the BASIC screen. A machine that has already been running would swallow those keys.
- **Landed in:** FR-1.

## 2026-10-04 — Platform menu, same dialog

- **Decision:** macOS and Windows get a File menu. Ctrl-O or Command-O opens the dialog on every platform. Linux keeps the shortcut because the window is not a GTK window.
- **Source:** The app is Win/Mac/Linux. The menu bar on Linux would require a different window toolkit.
- **Landed in:** FR-1.
