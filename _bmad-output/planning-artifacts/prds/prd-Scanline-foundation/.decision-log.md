# Decision log — Scanline foundation

Created: 2026-10-04
Status: draft

## 2026-10-04 — Fast path

- **Decision:** Own cores. Fuse and VICE stay reference material. The product is display stability and the picture.
- **Source:** Product discussion 2026-10-04.
- **Landed in:** Vision, non-goals.

- **Decision:** First round is Spectrum 48K, basic 128K (128 KB, two ROMs, port `7FFD`, AY), and C64 PAL. This PRD ships only the present pipe and a ROM-free pattern. CPUs are the next PRD.
- **Source:** Scope cut 2026-10-04.
- **Landed in:** Non-goals, FR-6.

- **Decision:** Rust core and host. One WGSL shader through wgpu, so Metal, Vulkan, and D3D12 share the present path.
- **Source:** Cross-platform requirement.
- **Landed in:** FR-1, FR-3, addendum.

- **Decision:** The core keeps per-scanline attributes, per-row border, and a separate sprite layer. The GPU samples that with nearest filtering at an integer scale.
- **Source:** Display-engine discussion.
- **Landed in:** FR-2, FR-3.

- **Decision:** Mixes are in linear light. Sharp pixels stay on the published palette bytes. Temporal blends a two-frame return and an in-row period-2 checker. Motion stays on the current frame.
- **Source:** Corrected temporal rule, 2026-10-04.
- **Landed in:** FR-4.

- **Decision:** 60 Hz panels use a fixed 6:5 cadence (`display_tick * 5 / 6`), not a film 3:2 pulldown. Audio sample count is the clock API. The window uses the 60 Hz pace until variable refresh is detected.
- **Source:** Frame-pacing discussion.
- **Landed in:** FR-5.

- **Decision:** ULA channels are `0x00`, `0xD7`, and `0xFF`. C64 colors are VICE `colodore.vpl` 3.6.1.
- **Source:** VICE tag v3.6.1, http://www.colodore.com/.
- **Landed in:** FR-3.
