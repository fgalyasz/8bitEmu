## 2026-10-04 — Fast path

- **Decision:** Loading sound defaults on. F4 and Sound → Loading sound toggle it. Off means the same ear pulses, with up to 32 extra frames per refresh after the load prompt, and the loading beeps discarded. The turbo stops when the tape is no longer playing, so the game is heard. No block is written straight into RAM.
- **Source:** Ferenc asked to switch the loading sound off, and to turbo-load when it is off.
