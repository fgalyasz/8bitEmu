## 2026-10-05 — Fast path

- **Decision:** Implement OUTI/OUTD/OTIR/OTDR and the matching input block opcodes. Saboteur II selects an AY register with OUT (C),A, then writes the value with OUTD. Without OUTD the chip stayed muted.
