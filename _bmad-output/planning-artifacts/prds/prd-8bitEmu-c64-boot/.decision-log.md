# Decision log

## D-1: First slice is text-mode boot

Fast path. Ship 6510 + banked map + VIC text + CIA-1 keyboard. SID and sprites wait. Matches the Spectrum “boot the machine” epic shape.

## D-2: Open ROMs, not Commodore dumps

`roms/README.md` already points at MEGA65/open-roms. Defaults use `c64-kernal.rom`, `c64-basic.rom`, `c64-chargen.rom`. No binaries in git.

## D-3: Separate C64 machine module

Keep Spectrum `Machine` intact. Add `c64` modules and a presenter host enum so Spectrum regressions stay unlikely.

## D-4: PAL frame budget

19656 cycles per frame (63×312). Not cycle-exact VIC; enough for KERNAL init and typing.
