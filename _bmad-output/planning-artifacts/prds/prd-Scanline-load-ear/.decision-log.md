# Decision log: Type LOAD and hear the tape

## 2026-10-04 — J is the LOAD keyword

- **Decision:** The prompt holds J, then the two quotes, then Enter. It does not spell L, O, A, D. The first key waits 100 frames so the editor is on the input line, and each key is held for 8 frames.
- **Source:** The 48K ROM is in keyword mode at the start of a line. J is token `0xEF` (LOAD). L is token `0xF1` (LET). Confirmed by running `roms/48.rom` locally.
- **Landed in:** FR-1.

## 2026-10-04 — Park the tape until the ear is polled

- **Decision:** The tape advances only after a frame reads port `0xFE` at least 64 times. Keyboard scanning stays under that. A loader crosses it, and the next frame plays the pulses.
- **Source:** Playing from reset consumes the pilot before LOAD starts, so a typed LOAD hears silence.
- **Landed in:** FR-2.
