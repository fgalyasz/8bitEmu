# Decision log — Spectrum 48K and 128K

Created: 2026-10-04
Status: draft

## 2026-10-04 — Fast path

- **Decision:** This increment boots a 48K or basic 128K machine from a user-supplied ROM and can load an SNA. The ROM-free picture stays the default when no file is passed.
- **Source:** Product request 2026-10-04.
- **Landed in:** Vision, FR-5.

- **Decision:** The Z80 covers the documented prefixed set. Undefined `ED` opcodes are 8-cycle NOPs. Flag bits 3 and 5 stay clear.
- **Source:** Scope of one hobby increment.
- **Landed in:** FR-1, non-goals.

- **Decision:** One maskable interrupt at the start of a 69888 T-state frame. No contention and no floating bus.
- **Source:** Games and the 128K ROM need the interrupt; contention is a later accuracy pass.
- **Landed in:** FR-2, non-goals.

- **Decision:** Looks move from keys 1/2/3 to F1/F2/F3 so the Spectrum can see the digit row.
- **Source:** The matrix and the old look keys share the same digits.
- **Landed in:** FR-3.

- **Decision:** Tape is not in this increment. SNA is the way to start a program that is not in the ROM.
- **Source:** A tape engine is a separate product slice.
- **Landed in:** Non-goals, FR-5.
