## 2026-10-04 — Fast path

- **Decision:** `./scripts/build-release.sh` builds a release binary for the host only. macOS and Linux ship as `scanline`. Windows ships as `scanline.exe`. The folder is `dist/scanline-<system>-<arch>/`. `arm64` is stored as `aarch64`. No cross-compile, no DMG, no ROM in the output.
- **Source:** Ferenc asked for a build script that produces the executable for Windows, macOS, and Linux, with a PRD and GitHub issues on the project board.
- **Landed in:** `prd.md` FR-1, FR-2.
