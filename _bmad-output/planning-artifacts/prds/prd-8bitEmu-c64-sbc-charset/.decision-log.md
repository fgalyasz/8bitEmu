# Decision log

## D-1: Root cause

`sbc_binary` cleared carry when it was set (and set when clear) before `adc_binary(!value)`, so `SEC; SBC` behaved like borrow already taken. Screen PETSCII→code used `SBC #$40` and produced codes one too low.
